# Repository guide for agent sessions

This repository is the **dsh-coding-preset** project: a curated set of
upstream skill repositories, vendored as git subtrees and installed into
DeepSeek Harness as a single agent preset named **Coding**.

## Layout

- `dsh/`: the preset project. `upstreams.mjs` is the manifest that drives
  everything; `cordis.patch.yml` is generated by `dsh/scripts/install.mjs`
  and must not be edited by hand.
- `upstreams/<name>/`: vendored copies of upstream repositories, synced with
  `git subtree pull --squash` via `npm run dsh:sync`. Each upstream keeps its
  own conventions, license, and docs; the mattpocock subtree in particular
  forbids em-dashes in its prose. Treat content under `upstreams/` as
  read-mostly: edit it only deliberately, because the next sync merges
  upstream changes into it.

## Rules

- To add, remove, or change which skill directories an upstream contributes,
  edit `dsh/upstreams.mjs`, then run `npm run dsh:validate` and
  `npm run dsh:install -- --generate-only`. Never hand-edit
  `dsh/cordis.patch.yml`.
- Skill names must be unique across ALL contributed roots: dsh resolves
  cross-root duplicates silently, and `dsh/scripts/validate.mjs` exists to
  fail on them instead.
- After touching anything under `dsh/` or `upstreams/`, run
  `npm run dsh:validate` before committing.
- Keep prose free of em-dashes everywhere in this repository, matching the
  convention of the vendored upstreams.
